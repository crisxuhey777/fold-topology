# 折叠时空 · 光影拓扑

> **Fold & Cast** — 一款纯原生、单文件、零依赖的几何解谜游戏。折叠纸张连通时空，驾驭光影破解 36 道拓扑谜题。

---

## ✨ 简介

在《折叠时空 · 光影拓扑》中，你需要**发射一束光**，通过**折叠纸张**、**旋转反射镜**、**拆分光谱**、**穿越虫洞**，让光线绕过黑洞、染上色彩，最终点亮终点水晶。

每一关都是一个小小的「顿悟（Aha!）」时刻——看似不可能连通的路径，只需一次折叠或一次恰到好处的旋转，光路便豁然贯通。

- 🧩 **36 个阶梯关卡**：横跨五大章节，从直射教学到「终焉·光之奇点」的全机制终章
- 🎨 **《纪念碑谷》式美学**：莫兰迪渐变、玻璃拟态 UI、程序化发光
- 🔊 **程序化音频**：禅意五声音阶 BGM + 全套交互音效（Web Audio 合成，零外部素材）
- 📱 **移动端完美适配**：原生竖屏 600×1000 黄金比例、全屏沉浸、Retina 高清、15° 磁吸触控、震动反馈
- ⚡ **单文件交付**：一个 `index.html` 双击即玩，无需构建、无需网络

## 🎮 核心机制

| 器具 | 功能 |
|---|---|
| 💡 **发射光源** | 点击发射一束白光，沿路径飞行、反射、折射 |
| ✂️ **折叠折痕** | 拖动两端点自定义折叠轴，折叠后右侧物件轴对称映射到左侧 |
| 🪞 **反射镜** | 正面反射光线；可 360° 旋转（15° 磁吸吸附） |
| 🔺 **三棱镜** | 光束穿透后一分为二（±20° 分光） |
| 🌀 **时空虫洞** | 光线射入 A 端，从 B 端以相同方向穿出（A↔B 互通） |
| 🎚️ **滑轨镜面** | 沿轨道拖拽平移，校准光路落点（对折态下自动反解坐标，跟手不漂移） |
| 💠 **滤光晶片** | 将白光染成青/红，仅同色水晶能被对应色光激活 |
| 🕳️ **黑洞** | 吞噬直射光线，迫使你绕行或折叠回避 |
| 🪐 **引力透镜** | 光线经过其边缘时产生优美的弧形弯曲偏折 |
| ⚡ **光能机关** | 光脉冲真实击中感应器后，能量门才淡出解体放行 |
| 💎 **终点水晶** | 被正确颜色的光线充能即通关 |

## 🕹️ 操作指南

### 桌面端
| 操作 | 方式 |
|---|---|
| 发射光线 | 点击光源，或底部 💡 按钮 |
| 折叠 / 展开 | 底部「对折」按钮，或 `空格` 键 |
| 旋转镜面 / 棱镜 | 点选后拖拽（15° 磁吸，按住 `Shift` 任意微调） |
| 平移滑轨镜面 | 拖拽镜面中心滑块旋钮 |
| 调整折痕角度 | 拖拽折痕两端金色旋钮 |
| 重置关卡 | 底部 ↺ 按钮 |
| 音乐开关 | 右上角 ♪ 按钮 |

### 移动端
- 单指拖拽旋转 / 平移 / 调折痕，触控判定已外扩（≥40px），无需精准点击
- 旋转到 15° 刻度时自动**磁吸锁死**并伴随轻微震动 + 齿轮微鸣
- 底部一体化玻璃拟态控制台，单手拇指即可盲操

## 🖥️ 技术实现

- **纯原生 HTML5 + CSS + ES6 + Canvas 2D + Web Audio API**，零第三方库、零图片/音频素材
- **Raycaster 光束树**：线段/圆/三角形求交，支持反射、分光、染色、虫洞瞬移，最大反射次数限制防死循环
- **折叠几何**：`P' = P − 2((P − A)·n)n` 轴对称镜像，支持任意角度折痕
- **渲染优化**：预渲染辉光精灵 + `globalCompositeOperation='lighter'` 加法混合（全程无 `shadowBlur`），锁定 60 FPS
- **程序化音频**：五声音阶低频垫乐 + 随机钟鸣 + 程序化混响，全部实时合成

## 🚀 运行与部署

### 本地运行
双击 `index.html` 即可在浏览器中游玩（推荐 Chrome / Edge / Safari / 微信内置浏览器）。

### 在线部署（GitHub Pages）
1. 将仓库推到 GitHub
2. 仓库 **Settings → Pages**，Source 选 `main` 分支、目录 `/ (root)`
3. 约 1 分钟后访问：`https://<用户名>.github.io/<仓库名>/`
